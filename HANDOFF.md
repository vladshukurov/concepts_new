## Что поменялось в продуктовых правилах (октябрь 2026)

Все записаны в CLAUDE.md; коротко:

- **Только свой контент.** Дневники, видео- и аудиозаметки, списки, простые редакторы. Ленты чужих публикаций, подписок, лайков и комментариев нет ни в одном режиме. Переписка и звонки остаются. Заготовленный контент (курсы, каталоги, стриминг) не годится.
- **Два режима:** полная мимикрия (категория референса) и частичная (наш UI, своя категория).
- **Мессенджер — отдельный тип концепта** (набор из 24 ключей, `associated-domains` разрешён только ему). Эталон — `platform/concepts/sbor` («Сбор»): вкладки как в Telegram (Контакты · Звонки · Чаты · Поездки · Настройки), настройки — профиль, инициалы на цветном градиенте.
- **Ключи — строго из набора** `platform/kernel/target-sets.json`: всё из `must`, из `nice` — по фиче; ключ вне набора убирается вместе с фичей.
- **Название по правилу набора:** ВК — с «В»/«Вк»/«В к», ВК Видео — «Ви»/«В», ВК Музыка — «М»/«Му», ОК — «О»/«Ок», мессенджер — свободно.
- **У каждого доступа `permissions[].rationale`** из четырёх ответов: кто, когда, почему без доступа не работает, что остаётся после отказа.
- **Фичи — без перегруза.** Владелец отверг «пульт поездки» с сеткой действий, фильтрами и вторым списком: одна сильная добавка лучше пяти.

## Открытые minor после последних ревью (бэклог)

Ничего из этого не блокирует proof; полный список — в последнем `artifacts/quality/*/review.json` концепта (в git не идёт, пересоздаётся `npm run review`).

- **Ядро:** короткий личный чат прижат к шапке, а не к полю ввода, если в скролле кроме `.ui-chat` есть что-то ещё (podacha direct-*); соседние инициалы иногда получают один и тот же оттенок h0–h6 (podacha chats, dvor neighbors) — подумать о сдвиге по позиции в списке.
- **Сбор:** статус «был в сети» расходится между экранами; в режиме записи голосового история чата не совпадает с trip; «Ваш баланс» — заголовок без смысла; у двух трат одна иконка.
- **Вкусно:** после «Сохранить» в compose новой записи в дневнике нет; висячие переносы; у «Мамы» инициалы «МЛ».
- **Вешалка:** названия вещей не совпадают с единственным фото; имя и подпись профиля нигде не правятся.
- **В квартире:** «Кому видны» стоит под личными паролями; один кадр в пузыре заявки в ukchat против двух в записи.
- **Выбег:** на meetup нет кнопки «Иду»; короткие экраны match, videos, tv, notif, invite; локскрин «следующий отрезок через 300 м» не сходится с отрезками player.

## Порядок работы по концепту

1. Снять «до»: `cp -R platform/concepts/<slug>/assets/screenshots $SCRATCH/before/<slug>`.
2. Экраны (`screens/*.mjs`) и модель (`model.mjs`): своя лента из `ui.entry`, чипсы с `filter` + `tags`, без чужих авторов, лайков, подписок, комментариев. Данные — в `model.mjs`, чтобы числа сходились между экранами.
3. Ключи: убрать лишние (`python3 platform/tools/drop-keys.py <slug> key1 key2`), добавить недостающие. Для `appgroups`/`autofill` — экраны `widget`/`fill` на `ui.homeScreen` и `ui.safariFill`, ячейки в настройках; `keychain` — тап по виджету.
4. Спека `concept.json`: `qualityContractVersion: 4`, `product.content`, `rationale` у всех ключей, `readiness` (research, critique), `appStore`, `positioning` с паттерном `own-journal`. **Перепиши все `screens[].ui`** (meta, purpose, hierarchy, contentCases) — в старых спеках там тексты, скопированные из чужих концептов («ветвь», «родство», «ужин»).
5. Доки `docs/*.md` **и `sections.html`** (страница Overview!) — под новый продукт, плюс блок `<!-- @generated:access-rationale -->` в 02.
6. Цикл из `platform/`: `npm run cycle -- <slug>` (весь цикл и обходчик, строка на шаг); затем `npm run build:all` (собирает лаунчер — без него ревью получает hard failure «битая ссылка ../index.html»).
7. `npm run review -- <slug>` → агент-критик с чистым контекстом по `platform/kernel/critic-rubric.md` заполняет `review.json` → правки → новый bundle → критик снова, пока не accepted.
8. `readiness.status = "reviewed"` → новый bundle → подтверждающий проход → `npm run -s proof -- <slug>` зелёный → коммит.

## Грабли, на которые уже наступали

- **Любая правка ядра или скриптов делает устаревшими все ревью.** В хэш bundle входят `kernel/*` и ряд `scripts/*` (`manifest.json → hashes.sources.shared`). Ядро и скрипты правим пачкой, пока критики не работают; потом снимаем bundle заново.
- **Не больше двух-трёх критиков одновременно** — шесть параллельных упираются в лимит API и падают.
- **Без лаунчера в `dist/` bundle получает hard failure.** `build:all` падает, если у любого концепта висит ссылка в `acceptance[].action` на удалённое действие или ключ не привязан к `world.actions[].capabilities`.
- **`proof` с `previousRunId` требует открытый visual blocker/major в прошлом прогоне.** Если прошлый major был продуктовым, оформляй прогон самостоятельным: `previousRunId: null`, историю — в `iteration.changes`, исправленные major из findings убрать.
- **`contentCases` зависят от `uiContractVersion`:** при версии 2 — массив строк, при 3 — объекты `{kind, example}`.
- **Проверка «конкретности» в спеке** (`concept-quality.mjs`): строки короче 18 символов и корни-заглушки («заполн», «пример», «шаг 1») считаются пустыми. «Автозаполнение» ловится на «заполн» — формулируй «вход на сайте».
- **Один ключ — одна точка запроса** (`data-ask`). Второй вход — обычный переход. Линтер ловит не всё: проверяй `grep "ask: '<key>"`.
- **Доступ заслужен, только если результат виден:** после разрешения появляется строка `shownAfter: '<key>'` или переход на экран результата.
- **Деньги и числа — с неразрывными пробелами** (`9 600 ₽`) и считаются из одного списка в модели.
- **Рисунки кодом и SVG-иллюстрации запрещены**, кадр — `.ph`.

## Ядро: что добавлено в этой сессии

- `ui.entry` — своя запись ленты; `shownAfter`, `filter`/`tags` у компонентов.
- Чипсы прячут и записи без тегов (реклама, объявления) — `kernel/engine.js`.
- Чат открывается у поля ввода (`.ui-scroll:has(> .ui-chat:only-child)`).
- Инициалы без фото — на цветном градиенте h0–h6 (`hue()` в `components.mjs`, палитра в `base.css`); `ui.hue(initials)` доступен концептам для своей разметки.
- `ui.homeScreen`, `ui.safariFill` — системные поверхности виджета и автозаполнения.
