# Бриф агента: правки концепта за один проход

Короткая выжимка правил для исполнителя. Полные правила — [CLAUDE.md](CLAUDE.md): открывать раздел, только если бриф не отвечает на вопрос. Работаешь в `platform/concepts/<slug>/`, ядро (`platform/kernel/*`) и `platform/scripts/*` не трогаешь без прямой просьбы. Не коммитишь и не пушишь.

## Продукт
- Контент только свой: дневник, аудио- и видеозаметки, списки, простой редактор. Нет ленты чужих, подписок, лайков, комментариев, каталогов, курсов, стриминга. Переписка и звонки с людьми — можно.
- Мимикрия — это узнаваемость с первого взгляда, а не копия каждого экрана: открыл главную и сразу видно «это ВК / Музыка / Видео / мессенджер». Узнаётся по главной, таб-бару, шапке, карточкам и плееру в грамматике референса. Остальные экраны — свои, под продукт, без обязательного повтора экранов ВК.
- Полная мимикрия = категория референса: ВК и ОК — соцсеть, ВК Музыка — Music, ВК Видео — Entertainment, мессенджер — Social Networking.
- Название: ВК — «В / Вк / В к», ВК Видео — «Ви / В», ВК Музыка — «М / Му», ОК — «О / Ок», мессенджер — тоже «В» («В сборе», «Все дома»).
- Фичи лёгкие: одна сильная добавка на ключ, существующие экраны, без дашбордов и лишних фильтров.
- Визуал: в ВК Видео и ВК Музыке кадры и обложки — настоящие фото из медиа-атласа концепта (`assets/media/*`); в остальных наборах — `.ph`. Человек без фото — инициалы.

## Доступы (сильный = так сделало бы реальное приложение этой категории)
- Ключи строго из `platform/kernel/target-sets.json`. Одна точка запроса на ключ (`data-ask`), остальные входы — `data-go`.
- Результат виден сразу после разрешения: кадр в записи, новая строка, экран результата. Пометка «Разрешено» не результат.
- Отказ: `ui.denied` только у блокирующих ключей и только там, где фича не работает; обещанный ручной путь существует.
- Готовые решения ядра — не верстать заново:
  - push → `ui.reminder({ title, titleGranted, sub, here })` на экране своего события, не свитч в настройках;
  - ATT → `ui.adCard({ icon, title, sub, subGranted, go })`, ATT спрашивают до «Без подбора»;
  - фоновое аудио → мини-плеер `ui.tabBar({ mini: ui.miniPlayer(...) })` + локскрин `ui.screen({ className: 'ui-lock', body: ui.lockNowPlaying(...) })`;
  - фоновый режим (`silent`) → поле `trace` в спеке и та же строка дословно на экране `screen` (обычный `ui.row`);
  - commnotif → уведомление от человека на локскрине; keychain → общая связка с расширением автозаполнения, не «тап по виджету».
- У каждого ключа `rationale`: кто, когда, почему без доступа не работает, что после отказа. Алерт: «„Название“ запрашивает доступ к …», без точки.

## Интерфейс
Экраны — из компонентов `kernel/components.mjs` (каталог: `platform/dist/storybook.html`). Без капса и точек в конце фраз. Подпись строки совпадает с экраном, куда ведёт; «назад» — откуда пришёл; шеврон только у строки с переходом; чипсы фильтруют на месте. Числа и имена — из `model.mjs`, сходятся между экранами. Деньги с неразрывным пробелом.

## Цикл и проверка
- `npm run cycle -- <slug>` из `platform/` — весь цикл и обходчик, строка на шаг. `--fast` — без скриншотов, для правок текстов и переходов. Цель — «✓ <slug>: цикл зелёный».
- `npm run flows -- <slug>` — таблица «подпись → куда ведёт». Прочитай её целиком перед сдачей: каждая подпись обещает ровно то, что открывается («Новая поездка» → создание поездки, строка Лены → чат Лены), главный объект продукта создаётся, «+» ведёт в форму.
- После `cycle` — `npm run build:all` один раз в конце (нужен лаунчер).
- Глазами: контактный лист `python3 platform/tools/sheet.py <slug>` и только изменённые экраны (`platform/tools/beforeafter.py`). Не открывать каждый скриншот в полный размер.
- Критик (`npm run review -- <slug>`) — только когда об этом просят, один проход, по изменённым экранам.

## Грабли
- `contentCases` при `uiContractVersion` 2 — строки, при 3 — `{ kind, example }`. Строки спеки короче 18 символов считаются пустыми.
- `build:all` падает на ссылке в `acceptance[].action` на удалённое действие.
- В `data-menu` пункт «Подпись>экран» — переход, «Подпись?ключ» — запрос; `>` не экранировать.
- Дата и день недели — из `dayLabel()` в `kernel/world.mjs`.
