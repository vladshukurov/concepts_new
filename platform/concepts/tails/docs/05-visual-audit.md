# Выгул — визуальный аудит

Аудит ведёт критик с чистым контекстом по `kernel/critic-rubric.md`: полноразмерные PNG всех экранов, листы и кропы — в `artifacts/quality/` (в git не идут). Машинные проверки — `npm run audit` и `npm run audit:grid`.

- Своя лента без чужих публикаций: прогулки, наблюдения, сроки и реклама кормов.
- Курс дрессировки и фоновое аудио убраны: заготовленный контент не годится по правилам проекта.
- Расширение «Поделиться» снято — его нет в наборе ВКонтакте.
