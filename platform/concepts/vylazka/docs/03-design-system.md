# Вылазка — дизайн-система

Тема `vk-dark` ядра: нейтрали, кегли и радиусы VKUI, акцент `#0077FF`.

## Своё

- `.vy-weather` — погода на выходные в шапке главной вместо аватара.
- `.vy-strip` — полоска маршрута: точки-привалы, отрезки по длине, пройденное акцентом, отметка «вы здесь» после разрешения геопозиции.
- `.vy-rcard` — горизонтальная карточка маршрута-серии: кадр 16:10, полоска точек, название и счёт вылазок.
- `.vy-next` — следующая вылазка: дата крупно слева, маршрут и выход справа.
- `.vy-map` — маршрут крупно с подписями точек и километрами.
- `.vy-player`, `.vy-chapters` — плеер 4:3 и подписанные главы по точкам маршрута под кадром.
- `.vy-cam-*` — съёмка привала: точка маршрута поверх видоискателя.

Кадры — `.v1…v9` из трёх атласов (`assets/media`): компания на тропе, мох у родника, сосны, закат над водой, северный мол, вода, турбаза, туман, волна. Люди — инициалы.
