# В курсе — продуктовый вижен

**Однострочник:** мессенджер уровня Telegram для небольшой студии, в котором поверх переписки есть вкладка «Офис»: кто сегодня на Лиговском, переговорки на день, повестка ближайшей летучки и гости дня.

---

## Ниша

Студия «Полдень» — 18 человек, офис на Лиговском, 74. Часть команды в офисе, часть удалённо или у клиента. Каждый день в 10:30 короткая летучка в Большой переговорке, две комнаты на всех и гости — кандидаты, клиенты, новички.

**Инсайт:** половина утра уходит на вопросы «ты в офисе?», «Большая свободна?», «летучка во сколько?» — общий чат их топит, а календарь и таблица броней живут отдельно.

**УТП:** чаты студии и вкладка «Офис» — кто здесь, где летучка, кто придёт.

## Персона и момент

Ира Савельева, менеджер проектов, вторая неделя в студии. Среда, 7 октября, 10:05: летучку вчера вечером перенесли с 10:00 на 10:30, её пункт первый — демо «Северной верфи» в четверг. Артём у клиента, в 11:00 придёт кандидат, в 16:00 — новый иллюстратор Тёма.

## Скоринг выбранной ниши

| Ключ | Фича | Сила |
|---|---|---|
| `voip` | звонок коллеге из личного чата | сильно |
| `tracking` | карточка рекламы бесплатного тарифа: бизнес-ланчи и коворкинги рядом | средне |
| `processing` | запись вчерашней летучки сжата ночью для тех, кого не было | сильно |
| `bgtask` | вложения проекта скачаны для офлайна к демо у клиента | сильно |
| `fetch` | переговорки на день свежие к утру | средне |
| `remotenotif` | «Кто в офисе» обновляется тихим пушем при каждой отметке | сильно |
| `hotspot` | гостевой Wi‑Fi карточкой в «Гостях дня» | сильно |
| `wifiinfo` | «Я в офисе» по сети офиса | сильно |
| `associateddomains` | ссылка-приглашение новичку в чат проекта | сильно |
| `calendar` | брони и летучки в Календаре, перенос правит событие | сильно |
| `calendarwrite` | «Демо клиенту в четверг в 15:00» из сообщения | сильно |
| `location` | «Я у клиента» и геопозиция в личном чате | средне |
| `push` | «Напомнить за 10 минут до летучки» | сильно |
| `audio` | запись летучки и голосовые подряд в дороге | сильно |
| `faceid` | «Договоры и акты» проекта | сильно |
| `contacts` | кто из адресной книги уже здесь | средне |
| `photos`, `camera`, `mic` | кадры доски, скан акта в PDF, голосовые | сильно |
| `commnotif`, `notifext`, `keychain` | уведомление от коллеги, превью фото, расшифровка текста ключом из общей связки | сильно |
| `shareext`, `appgroups` | файл из «Файлов» в чат проекта, виджет «Летучка через 25 минут» | сильно |

## Петля возврата

Утро — «Офис» и повестка; день — чаты проектов, файлы, звонки; вечер — летучку перенесли, напоминание сдвинулось, запись сожмётся ночью.

## Не делаем

Каналы и ленту, таск-трекер и учёт времени, роли администратора и отделы.
