# В курсе — продуктовый вижен

**Однострочник:** мессенджер уровня Telegram для небольшой студии, в котором поверх переписки есть вкладка «Летучка»: летучка без созвона — до 10:30 каждый пишет три строки «Вчера · Сегодня · Мешает», блокеры сверху, на самой летучке 2 минуты на человека и список «Договорились».

---

## Ниша

Студия «Полдень» — 18 человек, офис на Лиговском, 74. Часть команды в офисе, часть удалённо или у клиента. Каждый день в 10:30 короткая летучка в Большой переговорке, две комнаты на всех и гости — кандидаты, клиенты, новички.

**Инсайт:** летучка растягивается на полчаса пересказа «что я делал вчера», а то, что реально мешает, звучит последним или не звучит вовсе; решения никто не записывает.

**УТП:** чаты студии и летучка без созвона — три строки до 10:30, блокеры сверху, 2 минуты на человека.

## Персона и момент

Ира Савельева, менеджер проектов, вторая неделя в студии. Среда, 7 октября, 10:05: летучку вчера вечером перенесли с 10:00 на 10:30, апдейты написали 11 из 18, у Леры блокер — нет доступа к макетам клиента, а Ира ещё не написала свои три строки. Артём у клиента, в 11:00 придёт кандидат, в 16:00 — новый иллюстратор Тёма.

## Скоринг выбранной ниши

| Ключ | Фича | Сила |
|---|---|---|
| `voip` | звонок коллеге из личного чата | сильно |
| `tracking` | карточка рекламы бесплатного тарифа: бизнес-ланчи и коворкинги рядом | средне |
| `processing` | запись вчерашней летучки собрана ночью для тех, кого не было | сильно |
| `bgtask` | вложения проекта скачаны для офлайна к демо у клиента | сильно |
| `fetch` | переговорки на день свежие к утру | средне |
| `remotenotif` | «Апдейты команды» обновляются тихим пушем на каждый новый апдейт | сильно |
| `hotspot` | гостевой Wi‑Fi карточкой в «Гостях дня» | сильно |
| `wifiinfo` | «Отметить, что я в офисе» прямо в апдейте, по сети офиса | сильно |
| `associateddomains` | ссылка-приглашение новичку в чат проекта | сильно |
| `calendar` | брони и летучки в Календаре, перенос правит событие | сильно |
| `calendarwrite` | «Демо клиенту в четверг в 15:00» из сообщения | сильно |
| `location` | «Я у клиента» и геопозиция в личном чате | средне |
| `push` | «Напомнить написать апдейт в 10:00» | сильно |
| `audio` | запись прошлой летучки по говорящим в дороге, Now Playing на локскрине | сильно |
| `faceid` | «Договоры и акты» проекта | сильно |
| `contacts` | кто из адресной книги уже здесь | средне |
| `photos`, `camera`, `mic` | кадры доски, скан акта в PDF, голосовые | сильно |
| `commnotif`, `notifext`, `keychain` | уведомление от коллеги, превью фото, расшифровка текста ключом из общей связки | сильно |
| `shareext`, `appgroups` | файл из «Файлов» в чат проекта, виджет «Написали 11 из 18» | сильно |

## Петля возврата

Утро — три строки апдейта и блокеры команды; 10:30 — летучка по очереди и «Договорились»; день — чаты проектов, файлы, звонки; ночью собирается запись для пропустивших.

## Не делаем

Каналы и ленту, таск-трекер и учёт времени, роли администратора и отделы.
