# В курсе — референсы

Стратегия — полная мимикрия категории «мессенджер»: узнаётся с первого взгляда по списку чатов, переписке и таб-бару.

## Что взято из категории

- Telegram: список чатов с папками-чипсами, закреп под шапкой группы, сведения чата по касанию имени, «Избранное».
- WhatsApp: скрепка с камерой, галереей, файлом и геопозицией; звонок из шапки через CallKit; вкладка «Звонки».
- Slack и Teams: статус присутствия рядом с именем — здесь он ставится по сети офиса, а не руками.

## Чем «В курсе» не похож на референсы

- Вкладка «Офис» вместо историй и каналов: кто здесь, летучка, переговорки, гости.
- Летучка — объект с повесткой, напоминанием и сжатой записью, а не событие в чужом календаре.
- Строже по форме: радиусы 8–10 и аватары-скруглённые квадраты.

## Соседи по портфелю

«Сбор» — тот же каркас мессенджера для поездок группой; «В курсе» переиспользует его экраны и отличается нишей, вкладкой-ценностью и формой.
