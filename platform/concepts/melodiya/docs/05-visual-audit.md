# Визуальный аудит

Экраны сняты на 376×812.

- обложек у мелодий нет — play в строке и значки, фото только у трёх контактов, у остальных инициалы;
- в списках смешаны состояния: выбрана, не выбрана, запись ещё не мелодия, контакт под общую;
- длительности неровные: 0:48, 14:22, фрагменты 4, 16, 20 и 30 секунд;
- таб-бар и мини-плеер стоят на нижней границе, акцент только синий ВК.

## Матрица системных интеграций

| Интеграция | Видимый путь | Результат | Отказ |
|---|---|---|---|
| Camera | Контакты → Андрей → «Снять постер» | prompt → камера → «Так будет выглядеть звонок»: кадр во весь экран, имя, мелодия играет | карточка с инициалами, пустое состояние |
| Photos | Контакты → Катя → «Фото из «Фото»» | prompt → недавние снимки → фото на карточке Кати | карточка с инициалами, пустое состояние |
| Push | Контакты → Бабушка → «Напомнить поставить мелодию» | prompt → «Напомним 13 октября в 19:00» | карточка без напоминания |
| Background audio | Мелодии → Будильник → 7:00 → «Будить с погашенным экраном» | локскрин «7:00 · Подъём голосом Тёмы» → будильник | звук только с открытым экраном |
