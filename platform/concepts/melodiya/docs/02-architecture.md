# Архитектура

Три корневых раздела: «Мелодии», «Записи», «Профиль». Контактов как вкладки нет: назначение мелодии человеку — действие над мелодией, список контактов открывается из секции «Для контактов» на главной и из строки «Кому назначена» в редакторе мелодии (push с «назад»). Мелодия — полноэкранный плеер-редактор, контакт и будильник — push, новая мелодия — модально, камера — полноэкранно. Мини-плеер над таб-баром ведёт в играющую мелодию с любого корня.

Записи — файлы из «Диктофона» и «Файлов» на устройстве; мелодии (фрагмент, затухание, назначения) — в CoreData с синхронизацией CloudKit private database. Фото контакта хранится в его карточке.

Фоновое аудио — capability, а не разрешение: будильник и мелодии (AVPlayer) звучат с погашенным экраном, Now Playing на локскрине. Камера запрашивается только «Снять постер» у Андрея, «Фото» — только у Кати, уведомления — в карточке бабушки.

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | «Снять постер» в карточке Андрея | Андрей | Звонок с инициалами, мелодия звонка работает | Низкий |
| `NSPhotoLibraryUsageDescription` | «Фото из «Фото»» в карточке Кати | Катя | Карточка остаётся с инициалами | Низкий |
| `UIBackgroundModes: audio` | «Будить с погашенным экраном» в будильнике | Будильник | Без фонового режима мелодии звучат только с открытым экраном | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment` | «Напомнить поставить мелодию» в карточке бабушки | Бабушка | Напоминания нет, карточка бабушки остаётся в контактах | **Условный** — Локальное уведомление UNUserNotificationCenter |
