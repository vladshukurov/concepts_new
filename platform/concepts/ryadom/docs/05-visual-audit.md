# Выбег — визуальный аудит

Аудит ведёт критик с чистым контекстом по `kernel/critic-rubric.md`: полноразмерные PNG всех экранов, листы и кропы — в `artifacts/quality/` (в git не идут). Машинные проверки — `npm run audit` и `npm run audit:grid`.

## Решения

- Своя лента без чужих публикаций: записи — пробежки, заметки, цель недели и видео.
- Схема маршрута нарисована кодом — это данные маршрута, а не картинка; кадр видео — плейсхолдер.
- Universal Links и диплинки не заявлены.
