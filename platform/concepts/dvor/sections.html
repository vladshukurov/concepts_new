UI

30 экранов, четыре раздела в доке: Дом, Чаты, Двор, Меню. Семь системных поверхностей — камера, сканер, локскрин, фоновое обновление, замок, домашний экран с виджетом и звонок в CallKit — показаны отдельными экранами, потому что именно на них видно результат entitlement'а.

Domain

Подтверждение дома как правило доступа: житель получает право писать в ветку, если координаты в радиусе 150 м и SSID совпал с профилем дома. Всё остальное — темы, заявки, показания, события — привязано к подтверждённому дому, а не к подписке на кого-то.

Services

CLLocationManager и CNCopyCurrentNetworkInfo для пропуска, AVFoundation и DataScannerViewController для съёмки и наклейки роутера, SFSpeechRecognizer on-device для расшифровки, EventKit, LocalAuthentication, NEHotspotConfigurationManager, BGTaskScheduler с одним идентификатором app.dvor.refresh, PushKit и CallKit для вызова в квартиру.

Data

Показания счётчиков, хроника и черновики заявок — CoreData на устройстве. Пароли кабинета УК — Keychain общей группы с расширением автозаполнения. Снапшот для виджета и аватары для Notification Service Extension — контейнер group.app.dvor. Медиатека читается на месте, целиком не выгружается.

External

Своего сервера нет. Вход по почте или Google — SDK провайдера, ветки домов и чат — Firestore со security rules, аудио — Firebase Storage, уведомления — Firebase Cloud Messaging, карта и адреса — MapKit, реклама — рекламный SDK. Серверного кода не пишется: правила доступа это конфигурация.

{{PERM_MATRIX}}

Два ключа набора не заявлены, и это осознанно. com.apple.developer.associated-domains — диплинков в концептах не делаем вообще, поэтому фичи под него в сборке нет, а заявлять ключ без фичи нельзя. UIBackgroundModes: audio — фоновый playback защищается только реальной очередью и экраном Now Playing, а фича вышла слабой: убери её, и продукт не рассыплется. В отличие от звонка, ради которого voip в набор как раз вернули.

Почему бэкенда нет

Соцсеть без своего сервера — не фигура речи. Всё, что выглядело бы серверным, закрыто SDK провайдеров, системными фреймворками или данными на устройстве.

{{BACKENDLESS}}

Граница проведена так: «нет бэкенда» значит «не пишется серверный код». Вход по почте или Google требует SDK провайдера аутентификации — Firestore и Cloud Messaging это тот же SDK, а правила доступа к ветке дома описываются security rules, то есть конфигурацией. Ни одного обработчика, который надо было бы развернуть и поддерживать, в архитектуре нет.

{{SCREEN_TABLE}}

Дизайн-токены

Язык взят из набора VK-типа и отстроен: другой акцент, другая гарнитура, другой радиус контрола. Системный iOS-хром — статус-бар, permission-алерт, снекбар, home indicator — остаётся из ядра без правок.

Акцент

#0077FF — единый синий акцент набора VK. Им красятся активная вкладка, кольцо историй, главная кнопка; вторичные кнопки и значки строк — мягким синим.

Гарнитура

системный SF Pro для интерфейса, моноширинный SF Mono для данных: показаний счётчиков.

Поверхности

Серая страница #F2F3F5 и белые секции во всю ширину из темы ВК; свой блок — только внутри секции, серых плашек на белом нет.

Радиусы

Контрол 8, карточка 16, плитка 12, баббл 18, чип 5. Капсульных кнопок нет — это первое, что отличает раскладку от системной.

Плотность

Инсет контента 12 вместо 16–20, аватар в строке 52, шаг строк 20, заголовок экрана 22/800 слева с шевроном-дропдауном вместо крупного или центрированного.

Док

Четыре слота без подписей, аутлайн-иконки 26 со штрихом 1.9, активная красится акцентом, счётчик — красная пилюля, посаженная на угол иконки.

Данные кодом

Схема двора, этикетки счётчиков и поэтажный план подъезда рисуются разметкой: без них фича непонятна. Всё остальное медиа — плейсхолдер .ph.

Тёмные поверхности

Страница #0A0A0A, карточка #19191A: страница темнее контента, поэтому карточки «приподняты» без единой тени.
