# Архитектура

Основные сущности: знакомый, запись, рецепт, проверка, совместная готовка, разговор и сообщение. Запись принадлежит человеку и может ссылаться на его рецепт; проверка принадлежит рецепту; готовка использует зафиксированную версию шагов; разговор ужина всегда связан с готовкой и её текущим шагом.

Медиа хранится в управляемом Storage, данные — в Firestore с security rules, вход — через SDK провайдера и Keychain. Сообщения доставляются обычным push, именные Communication Notifications включаются в общих настройках, а телефон в топбаре кухни запускает настоящий групповой вызов через PushKit и CallKit. При отказе в микрофоне или VoIP вопрос остаётся доступен текстом.

## Обоснование доступов

Кто, когда и почему без доступа фича не работает — из `permissions[].rationale`.

<!-- @generated:access-rationale -->
| Ключ | Кто | Когда | Почему без доступа не работает | Что остаётся после отказа |
|---|---|---|---|---|
| `camera` | Человек у плиты с готовым блюдом | В новой записи нажимает «Снять блюдо» | Результат снимается сейчас, пока блюдо горячее; в галерее этого кадра нет | Запись из медиатеки или без кадра |
| `mic` | Человек, который снимает блюдо с пояснением | Нажимает «Снять с пояснением» или голосовое в чате | Видео со звуком и голосовые пишутся только с микрофона | Видео без звука, текст вместо голосового |

| `calendar` | Человек, которого позвали на ужин в пятницу | На «Пельмени втроём» нажимает «Добавить в календарь» | Событие ужина создаётся в календаре рядом с другими делами — без доступа на запись его не создать | Время ужина остаётся в приложении |
| `push` | Человек, который готовит со знакомыми | В настройках включает «Напоминания» | Напоминание приходит, пока приложение закрыто, — иначе начало ужина легко пропустить | Напоминание видно при открытии |
| `tracking` | Человек, которому показывают рекламу рынков и доставки | Выбирает подбор в «Конфиденциальности» | Без разрешения реклама рынков не учитывает район | Реклама без подбора, дневник бесплатный так же |
| `audio` | Человек у плиты с занятыми руками | В рецепте нажимает «Слушать с погашенным экраном» | Шаги своего рецепта звучат с погашенным экраном и управляются с локскрина | Шаги читаются с экрана |
| `localnetwork` | Человек, который готовит по шагам на кухне с ТВ | Нажимает «Найти экран на кухне» | Apple TV на кухне находится только поиском в домашней сети | Шаги и таймер остаются на экране телефона |
| `wifiinfo` | Человек на экране выбора ТВ | Выбирает «Кухня · Apple TV» | Имя сети подтверждает, что телефон и ТВ в одной домашней сети | ТВ выбирается вручную |
| `remotenotif` | Человек, которому знакомая ответила в чате | Без жеста: приходит ответ | Тихий пуш подгружает ответ в чат до открытия приложения | Ответ подгружается при открытии |
| `fetch` | Человек, который открывает дневник вечером | Без жеста, к первому открытию | Список покупок и шаги сегодняшнего ужина подтягиваются в фоне | Обновление в момент открытия |
| `processing` | Человек, который готовил по своему рецепту | Ночью на зарядке, без жеста | Видео шагов из своих фото собирается долгой задачей — днём это съело бы батарею | Шаги остаются фото |
| `bgtask` | Человек, записанный на ужин вместе | Перед началом ужина, без жеста | Без зарегистрированного идентификатора iOS не скачает шаги и таймеры заранее | Шаги скачиваются при открытии |
| `keychain` | Человек, который готовит и отходит от телефона | Нажимает на виджет шага на экране «Домой» | Сессия лежит в общей связке ключей — иначе из виджета открывается экран входа | Повторный вход по номеру и паролю |
| `commnotif` | Человек в чате ужина | В настройках включает «Сообщения ужина» | Уведомление показывает имя и аватар того, кто написал | Обычное уведомление без имени |
| `voip` | Человек в чате ужина | Нажимает «Позвонить» в шапке чата ужина | Входящий звонок ужина приходит на заблокированный экран только через VoIP-пуш и CallKit | Переписка и голосовые в чате |

| `appgroups` | Человек, который готовит и отходит от телефона | Ставит виджет из «Настроек» | Виджет читает шаг и таймер только через общую группу приложения | Шаг виден только в приложении |
| `autofill` | Человек, который заказывает продукты к пятнице | Открывает сайт доставки в Safari со входом из «Вкусно» | Телефон и пароль доставки подставляются в Safari без копирования | Пароль вводится вручную |

## Сценарные прототипы

Полный обзор дополняют девять независимых путей: вход, запись блюда, поиск по дневнику, совместная готовка, сохранение рецепта, кухонный экран, сообщения, знакомые и настройки доступов. Каждый прототип начинается в точке реального намерения пользователя, содержит только нужные экраны и ведёт собственный журнал разрешений.

## Отказы и приватность

Камера заменяется выбором готового фото, место — ручным вводом, распознавание шага — экранными контролами, кухонный экран — телефоном, а голосовые и звонок — обычным сообщением. Контакты сопоставляются только после явного действия; рекламный трекинг, фоновые режимы и именные уведомления включаются в настройках, а не запрашиваются при старте.
