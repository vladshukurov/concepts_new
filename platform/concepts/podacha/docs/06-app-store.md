# App Store

Категории: Social Networking / Food & Drink. Возраст: 13+. Бесплатно; один контекстный промо-блок. ATT запрашивается только по явной кнопке настройки рекомендаций. Фото, камера, микрофон, контакты, место, календарь и Wi‑Fi имеют отдельные действия и рабочие fallback-сценарии.

Разговор ужина открывается из вкладки «Мессенджер» и сохраняет контекст текущего шага. Телефон в шапке чата запускает настоящий групповой VoIP-вызов ведущей и участников через CallKit; без доступа вопрос можно задать текстом. Именные уведомления включаются только в Профиль → Настройки → Сообщения ужина.
