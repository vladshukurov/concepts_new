# Визуальный аудит

- главная отличается от соседей по набору: вместо обложки-героя — карточка-микс «Вечер» и таймер сна;
- обложки — фото из `assets/media`, у части записей значок;
- голоса — инициалы;
- длительности неровные: 4:40, 5:10, 4:10, 6:20.

| Интеграция | Путь | Результат | Отказ |
|---|---|---|---|
| Camera | Колыбельные → Котя-коток → «Снять обложку» | видоискатель → обложка в колыбельной | пустое состояние, значок |
| Photos | Колыбельные → + → «Обложка из «Фото»» | альбом «Соня» → «Обложка выбрана» | пустое состояние в разделе «Обложка» |
| Push | Вечер → «Напомнить начать укладывание» | «Напомним в 20:30 · укладывание», строка на главной | без напоминания |
| Background audio | Плеер → значок замка | локскрин «Засыпаем · ещё 12 минут» | звук с включённым экраном |
