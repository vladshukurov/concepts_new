# Архитектура

21 экран продукта, три корневых раздела, как в ВК Музыке: «Сегодня», «Колыбельные», «Голоса». «Вечер · на сон» — плейлист из главной, плеер — полноэкранно, камера — из колыбельной, форма «Новая колыбельная» — модально. Мини-плеер над таб-баром ведёт в плеер с любого корня.

Записи — файлы из «Диктофона» и «Файлов» на устройстве; вечер, голоса и обложки — в CoreData с синхронизацией CloudKit private database. Таймер сна работает на устройстве и затухает громкость.

Background audio — capability, а не пользовательское разрешение. Камера запрашивается только «Снять обложку» в колыбельной; «Фото» — только «Обложка из «Фото»» в новой колыбельной; уведомления — «Напомнить начать укладывание» в «Вечере».
