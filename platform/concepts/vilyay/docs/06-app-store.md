# Виляй — App Store и review notes

Entertainment. Семейный канал своего пса: ролики снимают сами члены семьи и смотрят вместе. Аккаунт опционален: «Продолжить без аккаунта» сразу открывает главную.

Заявлены девять возможностей набора ВК Видео: Local Network, Camera, Microphone, Photos read, Photos add, Notifications, Location When In Use, Background Audio и ATT. Associated Domains не заявлен: диплинков нет.

Review route:

1. «Создать» → «Снять Рыжика» → «Снять Рыжика» спрашивает камеру, затем микрофон; после записи ролик сразу стоит первым в сезоне «Сейчас».
2. У нового ролика «Отметить, где снято» спрашивает геопозицию; появляется «Парк Дружбы, у пруда».
3. «Сезоны» → «Рыжик против пылесоса» → «Смотреть на телевизоре» спрашивает Local Network; появляется «Телевизор в гостиной». Отказ — пустое состояние, серии смотрят на телефоне.
4. «Сезоны» → «Щенок» → «Добавить видео щенка из «Фото»» спрашивает Photos; выбранное видео встаёт в сезон.
5. «Сезоны» → «Первый год» → «Сохранить сезон «Первый год» в «Фото»» спрашивает add-only; появляется строка фильма в «Фото».
6. Главная → «Год назад сегодня» → «Напомнить: год назад Рыжик впервые увидел снег» спрашивает уведомления.
7. Главная → ролик → «Картинка в картинке» продолжает видео поверх других приложений; стрелка вниз сворачивает плеер в мини-плеер.
8. Главная → карточка корма → «Подбирать по интересам» показывает ATT до выбора «Без подбора».
