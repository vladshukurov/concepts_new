# В карандаше — визуальный аудит

Аудит ведёт критик с чистым контекстом по `kernel/critic-rubric.md`: полноразмерные PNG всех экранов, листы и кропы — в `artifacts/quality/` (в git не идут). Машинные проверки — `npm run audit` и `npm run audit:grid`.

- Первый экран — вход, а не скетчбук.
- Своя лента без чужих работ: зарисовки, серии, заметки, встреча и реклама материалов.
- Рисунки кодом убраны: лист — плейсхолдер, как требует правило проекта.
