# Визуальный аудит

Экраны сняты на 376×812.

- обложки — только у двух пьес из четырёх, у остальных значок ноты;
- в списках смешаны состояния: разучиваю, выучено, без записи, запись из «Файлов»;
- темп и длительности неровные: 72 → 96, 3:12, 3:30, 2:58, 25 мин;
- таб-бар и мини-плеер стоят на нижней границе, акцент только синий ВК.

## Матрица системных интеграций

| Интеграция | Видимый путь | Результат | Отказ |
|---|---|---|---|
| Camera | Пьесы → Испанский романс → «Сфотографировать ноты» | prompt → камера с рамкой → «Ноты · страница 2», строка в разделе «Ноты» | пьеса, пустое состояние |
| Photos | Пьесы → + → «Ноты и табы из «Фото»» | prompt → снимки нот и табов → два снимка в форме и в новой пьесе | форма, пустое состояние |
| Push | Занятия → сегодня → «Напомнить позаниматься в 19:00» | prompt → «Напомним завтра в 19:00», на главной «Завтра в 19:00 · Испанский романс» | занятие без напоминания |
| Background audio | Главная → Метроном → «Играть с погашенным экраном» | локскрин «Метроном · 96 ударов», «Открыть «Метроном»» → метроном | звук только с открытым экраном |
