# Карточка App Store

**Название:** В кругу — дневник партий
**Подзаголовок:** Свои партии и столы
**Категория:** Social Networking / Entertainment
**Возраст:** 13+

Ревьюер может пройти по предзаполненному телефону и паролю либо использовать гостевой вход. Для проверки голоса открыть Столы → Лесные союзы → Счёт; для background audio — Игры → Лесные союзы → Памятка. Контекстный чат открывается из вкладки «Мессенджер» или карточки стола, телефон в его топбаре запускает реальный групповой VoIP-вызов через CallKit. Именные уведомления включаются только в Профиль → Профиль → Настройки → Сообщения.

Privacy labels включают номер телефона, пользовательский контент и приблизительное место. Трекинг и покупки не заявлены.
