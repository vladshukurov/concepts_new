# Архитектура

## Модули

- `RunPlan` и `RunSession` в SwiftData.
- `FrameGuide` и `RunRecorder` на AVFoundation и Vision: видео, звук, уровень голоса; режим «Только звук» без камеры.
- `BlockRetake` пишет один блок по его плану и сравнивает дубль с прошлым.
- `TimelineEngine` сравнивает фактические блоки и метки с планом.
- `LocalPlayback` играет последний прогон, в фоне — через Now Playing.
- `TVPrompter` — Bonjour-поиск телевизоров в сети и вывод таймера со следующим блоком.
- `RunLikeFinder` — PHAsset: видео 5–10 минут, сверка с регламентом.
- `VenuePicker` — поиск площадки по названию; `TravelTime` — CLLocationManager один раз + MKDirections, координаты не сохраняются.
- `RehearsalReminder` — локальное уведомление на 20:00 накануне выступления.
- `AdsService` — рекламный SDK; IDFA только после ATT.
- `PhoneAuthService` использует SDK провайдера; токен хранится в Keychain.
- `PermissionsService` — девять возможностей, ни одна не запрашивается на входе.

## Внешняя инфраструктура

SDK входа — почта и пароль, рекламный SDK — показы. Напоминания локальные. Ни одна из этих систем не хранит прогоны, метки или видео пользователя.

<!-- @generated:access-rationale -->
| Ключ | Кто | Когда | Почему без доступа не работает | Что остаётся после отказа |
|---|---|---|---|---|
| `camera` | Человек, который готовит выступление и хочет увидеть себя со стороны | Нажимает «Начать прогон» в настройке, сразу после ответа про микрофон | Жесты, взгляд и кадр видны только на видео — без камеры их нечем разбирать | Прогон всё равно идёт и пишется звуком: экран записи показывает «Только звук» и волну, разбор по времени блоков остаётся |
| `mic` | Человек, который репетирует доклад вслух | Нажимает «Начать прогон» — первый запрос перед камерой | Речь, паузы и затянутые блоки слышны и считаются только по записи с микрофона | Таймер блоков идёт, но прогон не записывается; экран записи показывает «Нет доступа к микрофону» и путь в Настройки |
| `photos` | Человек, которого уже снимали на телефон или на созвоне | В профиле нажимает «Добавить прогон из Фото» | Приложение само отбирает видео, похожие на прогон по длительности относительно регламента 7:00 — для этого нужно читать список видео | Профиль показывает пустое состояние «Фото»; прогоны записываются в приложении |
| `photosadd` | Человек с удачным моментом прогона | На экране момента нажимает значок сохранения рядом с «Повторить только блок» | Фрагмент сохраняется в «Фото» только с этим доступом | Фрагмент остаётся в разборе и в профиле |
| `location` | Человек, который выступает в незнакомом месте | На карточке ближайшего выступления нажимает «Сколько ехать» | Время в пути и час выхода считаются только от того, где человек сейчас | На карточке — пустое состояние геопозиции, адрес площадки остаётся |
| `localnetwork` | Человек, который репетирует дома перед телевизором, а телефон стоит на штативе | В настройке прогона нажимает «Таймер на телевизоре» | Телевизор в комнате находится только поиском в локальной сети, без него таймер мелкий и на штативе | Пустое состояние локальной сети в настройке; таймер и блоки остаются на iPhone |
| `audio` | Человек, который повторяет доклад по дороге на выступление | На главной у последнего прогона нажимает «Слушать» | Запись прогона звучит с погашенным экраном и управляется с локскрина | Звук останавливается при блокировке |
| `push` | Человек с выступлением через несколько дней | На карточке выступления нажимает «Напомнить о прогоне накануне» | Вечером накануне приложение закрыто — напомнить о прогоне может только уведомление | Карточка выступления остаётся на главной, напоминание не придёт |
| `tracking` | Пользователь бесплатной версии | Тапает карточку рекламы на главной и выбирает «Показывать по интересам» | Подбор по интересам использует данные других приложений и сайтов только с разрешения | Реклама без подбора; карточка на главной помечена «без подбора» |

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | «Начать прогон» в настройке прогона — после микрофона | Прогон | Прогон пишется только звуком: волна, паузы и время блоков | Низкий |
| `NSMicrophoneUsageDescription` | «Начать прогон» в настройке прогона | Прогон | Прогон идёт по таймеру без записи; на экране записи — пустое состояние микрофона | Низкий |
| `NSPhotoLibraryUsageDescription` | «Добавить прогон из Фото» в профиле | Профиль | Новые прогоны записываются в приложении | Низкий |
| `NSPhotoLibraryAddUsageDescription` | Значок сохранения рядом с «Повторить только блок» на экране момента | Момент выступления | Фрагмент остаётся в истории прогонов | Низкий |
| `NSLocationWhenInUseUsageDescription` | «Сколько ехать» на карточке выступления на главной | Главная | Адрес площадки остаётся на карточке, время в пути не считается | Низкий |
| `NSLocalNetworkUsageDescription (+ NSBonjourServices)` | «Таймер на телевизоре» в настройке прогона | Прогон | Таймер и блоки остаются на экране iPhone | Средний |
| `UIBackgroundModes: audio` | «Слушать» у последнего прогона на главной | Главная | Звук прогона играет, пока приложение открыто | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment (Push Notifications capability)` | «Напомнить о прогоне накануне» на карточке выступления | Главная | Выступление и план остаются на главной, напоминание не придёт | **Условный** — UNUserNotificationCenter: локальное уведомление на вечер накануне, без сервера |
| `NSUserTrackingUsageDescription` | «Показывать по интересам» на экране рекламы | Реклама | Карточка рекламы остаётся без подбора, прогоны и разбор работают полностью | **Условный** — ATT показывается на экране выбора рекламы до «Оставить без подбора»; IDFA уходит только рекламному SDK |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

```

    │   └─ Аккаунт (account) — push, без таб-бара · открывается: «Профиль и аккаунт»
```
