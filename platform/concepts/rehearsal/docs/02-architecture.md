# Архитектура

## Модули

- `RunPlan` и `RunSession` в SwiftData.
- `FrameGuide` и `RunRecorder` на AVFoundation и Vision: видео, звук, уровень голоса.
- `TimelineEngine` сравнивает фактические блоки и метки с планом.
- `LocalPlayback` играет дорожку блока, в фоне — через Now Playing.
- `VenuePicker` — CLLocationManager + MKLocalSearch, координаты не сохраняются.
- `AdsService` — рекламный SDK; IDFA только после ATT.
- `PhoneAuthService` использует SDK провайдера; токен хранится в Keychain.
- `PermissionsService` — девять возможностей, ни одна не запрашивается на входе.

## Внешняя инфраструктура

SDK входа — номер и пароль, рекламный SDK — показы; Cloud Messaging — шаблоны плана. Ни одна из этих систем не хранит прогоны, метки или видео пользователя.

|---|---|---|---|---|

| `mic` | Человек, который репетирует вслух | Проверяет кадр и звук вместе с камерой | Речь и паузы слышны только в записи с микрофона | Прогон без звука, разбор по времени блоков |
| `photos` | Человек, которого уже сняли на телефон | В профиле нажимает «Добавить прогон из Фото» | Старый прогон лежит в «Фото» — без доступа его не разобрать | Только новые прогоны в приложении |
| `photosadd` | Человек с удачным моментом прогона | На экране момента нажимает сохранение | Фрагмент сохраняется в «Фото» только с этим доступом | Момент остаётся в приложении |
| `location` | Человек, который выступает на площадке | В настройке прогона выбирает «Площадка» | Площадки рядом подбираются только от текущего места | Площадка вводится вручную |
| `localnetwork` | Человек, который разбирает прогон с коллегой | В разборе нажимает AirPlay | Телевизор в переговорной находится только поиском в локальной сети | Разбор на телефоне |
| `audio` | Человек, который слушает свой блок в дороге | На экране момента нажимает «Слушать в фоне» | Дорожка блока звучит с погашенным экраном и управляется с локскрина | Звук останавливается при блокировке |
| `push` | Человек, который часто выступает | В настройках включает «Новые шаблоны плана» | О новом шаблоне приходит удалённое уведомление из панели провайдера, пока приложение закрыто | Новый шаблон виден в настройке прогона с пометкой «Новый» |
| `tracking` | Пользователь бесплатной версии | На экране рекламы нажимает «Показывать по интересам» | Без разрешения реклама не использует данные других приложений и сайтов | Реклама без подбора, всё работает так же |

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->

|---|---|---|---|---|

| `NSMicrophoneUsageDescription` | «Проверить кадр и звук» — вместе с камерой | Прогон | Прогон пишется без звука, паузы и темп не считаются | Низкий |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Вход по номеру (phone) — старт, без таб-бара · открывается: старт
    ├─ Пароль (password) — push, без таб-бара · открывается: «Далее»
    │   └─ Аккаунт (account) — push, без таб-бара · открывается: «Профиль и аккаунт»
    │       └─ Удаление аккаунта (deleteaccount) — push, без таб-бара · открывается: «Удалить аккаунт»
    ├─ Создать аккаунт (register) — push, без таб-бара · открывается: «Создать аккаунт»
    │   └─ Пароль нового аккаунта (registerpassword) — push, без таб-бара · открывается: «Далее»
    └─ Главная (today) — tab (root, start) · открывается: «Продолжить без аккаунта», «Войти» …
        ├─ Профиль (history) — tab (root) · открывается: вкладка таб-бара · photos
        │   ├─ Видео (import) — system picker · открывается: «Добавить прогон из Фото» (photos)
        │   └─ Настройки (settings) — push · открывается: «Настройки», «Показывать по интересам» (tracking) · push
        │       └─ Реклама (ads) — push · открывается: «Петличка за 1 990 ₽», «Реклама» · tracking
        └─ Прогон (setup) — push · открывается: «Начать прогон», «Демо для команды» … · camera, mic, location
            ├─ Площадка (place) — push · открывается: «Площадка» (location)
            ├─ Кадр и звук (frame) — fullscreen · открывается: «Проверить кадр и звук» (camera + mic)
            └─ Идёт прогон (recording) — fullscreen · открывается: «Начать прогон», «Продолжить прогон» …

                    └─ AirPlay (cast) — system · открывается: «Смотреть на телевизоре» (localnetwork)
```
