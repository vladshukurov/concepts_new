# Карточка App Store

**Name:** Второй дубль: прогон на видео
**Subtitle:** Запись, разбор, повтор
**Category:** Photo & Video / Education
**Price:** бесплатно, с рекламой

Для review: почта и пароль из `appStore.reviewAccount`. На экранах входа нет запросов доступов.

Маршрут ревьюера:

1. Главная → «Начать прогон» → в настройке «Начать прогон» спрашивает микрофон, затем камеру и открывает «Кадр и звук». Отказ в камере — запись «Только звук», отказ в микрофоне — таймер без записи.
2. Главная → «Сколько ехать» на карточке выступления спрашивает геопозицию и показывает время в пути.
3. Главная → «Напомнить о прогоне накануне» спрашивает уведомления; строка меняется на «Напомним в среду в 20:00».
4. Главная → «Слушать» у последнего прогона включает фоновое аудио и Now Playing на локскрине.
5. Главная → рекламная карточка → «Показывать по интересам» показывает ATT и возвращает на главную, где карточка помечена «по интересам».
6. Настройка прогона → «Таймер на телевизоре» спрашивает локальную сеть; в записи видна плашка телевизора.
7. Разбор → момент → «Повторить только блок» пишет только блок и показывает «3:18 → 2:51»; кнопка сохранения спрашивает добавление в «Фото».
8. Профиль → «Добавить прогон из Фото» спрашивает «Фото» и открывает «Похоже на прогоны».

Прогоны, метки и видео не отправляются разработчику. IDFA уходит рекламному SDK только после согласия.
