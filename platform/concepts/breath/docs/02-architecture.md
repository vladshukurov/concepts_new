# Архитектура

14 экранов, три корневых раздела, как в ВК Музыке: «Главная», «Практики», «Любимое». Профиль открывается push‑переходом из шапки главной. Detail и search — push, player — полноэкранно, result — завершение player. Мини-плеер над таб-баром ведёт в player с любого корня. Back возвращает на непосредственного родителя; root‑табы не складываются в стек.

Музыка и метаданные поставляются подписанным статическим content pack через CDN. Сохранённые сессии и история живут в CoreData с опциональной синхронизацией CloudKit private database.

Background audio — capability, а не пользовательское разрешение. Associated Domains не заявлен: диплинков нет. Камера запрашивается только из «Визуала сессии»; кадр анализируется локально и не сохраняется. PHPicker получает только выбранное фото и не требует доступа ко всей медиатеке. Push запрашивается только после явного действия в профиле.

| `push` | Человек, который собирает свои практики | В профиле включает «Новые ритмы и звуки» | О новом ритме приходит удалённое уведомление из панели провайдера, пока приложение закрыто | Новый ритм виден в «Практиках» |

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | Считать свет комнаты | Визуал сессии | Ручной ввод и выбор из «Фото» остаются доступны | Низкий |
| `NSPhotoLibraryUsageDescription` | Выбрать цвет из фото | Визуал сессии | PHPicker не требует доступа ко всей библиотеке; камера и стандартный визуал остаются | Низкий |
| `UIBackgroundModes: audio` | «Слушать в фоне» в плеере | Тихий берег | Плеер предупредит, что экран должен оставаться активным | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment` | Свитч «Новые ритмы и звуки» в профиле | Профиль | Новый ритм виден в «Практиках» | **Условный** — Реальная регистрация APNs |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Вход по номеру (phone) — старт, без таб-бара · открывается: старт
    ├─ Пароль (password) — push, без таб-бара · открывается: «Далее»
    │   └─ Аккаунт (account) — push, без таб-бара · открывается: «Профиль и аккаунт»
    │       └─ Удаление аккаунта (deleteaccount) — push, без таб-бара · открывается: «Удалить аккаунт»
    └─ Создать аккаунт (register) — push, без таб-бара · открывается: «Создать аккаунт»
        └─ Пароль нового аккаунта (registerpassword) — push, без таб-бара · открывается: «Далее»

Главная (home) — tab (root, start) · открывается: «Продолжить без аккаунта», «Войти» …
    ├─ Практики (discover) — tab (root) · открывается: «Весь обзор»
    │   └─ Поиск (search) — push · открывается: «Поиск», «Моя практика или звук» …
    ├─ Тихий берег (detail) — push · открывается: «Тихий берег», «Сменить ритм» …
    │   └─ Тихий берег (player) — fullscreen · открывается: «Слушать «Тихий берег»», «Окно ночью» … · audio
    │       ├─ Экран погас (background) — system · открывается: «Слушать в фоне» (audio), «Фоновое аудио»
    │       └─ Сессия завершена (result) — modal · открывается: «Завершить»
    ├─ Любимое (library) — tab (root) · открывается: «Вся история», «Сохранить в «Любимое»»
    ├─ Визуал сессии (studio) — push · открывается: «Визуал сессии», «Визуал сессий» … · camera, photos
    │   ├─ Считать свет комнаты (capture) — fullscreen · открывается: «Считать свет камерой» (camera)
    │   └─ Фото (pick) — system picker · открывается: «Взять цвет из фото» (photos)
    └─ Профиль (profile) — push · открывается: «Профиль» · push
```
