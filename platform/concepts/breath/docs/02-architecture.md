# Архитектура

13 экранов, три корневых раздела, как в ВК Музыке: «Главная», «Наброски», «Любимое». Профиль открывается из шапки главной. Песня и поиск — push, плеер — полноэкранно, съёмка — полноэкранно из песни, «Текст добавлен» — модально после снимка. Мини-плеер над таб-баром ведёт в плеер с любого корня.

Свои записи — файлы из «Диктофона» и «Файлов» на устройстве; версии, метки и текст — в CoreData с синхронизацией CloudKit private database. Фото страниц блокнота и видео из «Фото» хранятся в песне.

Background audio — capability, а не пользовательское разрешение. Associated Domains не заявлен. Камера запрашивается только «Снять текст из блокнота» в песне; «Фото» — только «Добавить из «Фото»» в новом наброске, чтобы показать видео и снимки дня записи (PhotoKit по дате файла). Уведомления — «Напомнить вернуться завтра» на экране «Текст добавлен». С локскрина «Открыть «Мотив»» возвращает в плеер.

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | «Снять текст из блокнота» в песне | Припев про дождь | Текст песни можно набрать вручную, фото страницы — добавить из «Фото» | Низкий |
| `NSPhotoLibraryUsageDescription` | «Добавить из «Фото»» в новом наброске | Новый набросок | Набросок сохраняется без видео и обложки | Низкий |
| `UIBackgroundModes: audio` | «Слушать в фоне» в плеере | Припев про дождь · v3 | Без фонового режима звук останавливается при блокировке, слушать можно с открытым экраном | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment` | «Напомнить вернуться завтра» после снимка текста | Текст добавлен | Напоминания нет, песня остаётся в «Последних» на главной | **Условный** — Регистрация APNs через SDK провайдера |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Вход по номеру (phone) — старт, без таб-бара · открывается: старт
    ├─ Пароль (password) — push, без таб-бара · открывается: «Далее»
    │   └─ Аккаунт (account) — push, без таб-бара · открывается: «Профиль и аккаунт»
    │       └─ Удаление аккаунта (deleteaccount) — push, без таб-бара · открывается: «Удалить аккаунт»
    └─ Создать аккаунт (register) — push, без таб-бара · открывается: «Создать аккаунт»
        └─ Пароль нового аккаунта (registerpassword) — push, без таб-бара · открывается: «Далее»

Главная (home) — tab (root, start) · открывается: «Продолжить без аккаунта», «Войти» …
    ├─ Наброски (discover) — tab (root) · открывается: «Все наброски»
    │   ├─ Поиск (search) — push · открывается: «Поиск», «Поиск по наброскам»
    │   └─ Новый набросок (new) — modal · открывается: «Новый набросок», «Готово» · photos
    │       └─ Добавить из «Фото» (pick) — system picker · открывается: «Добавить из «Фото»» (photos)
    ├─ Припев про дождь (detail) — push · открывается: «Куплет про электричку», «Припев про дождь» … · camera
    │   ├─ Припев про дождь · v3 (player) — fullscreen · открывается: «Без названия 14», «Припев про дождь · v3» … · audio
    │   │   └─ Экран погас (background) — system · открывается: «Слушать в фоне» (audio)
    │   └─ Текст из блокнота (capture) — fullscreen · открывается: «Снять текст из блокнота» (camera)
    │       └─ Текст добавлен (result) — modal · открывается: «Снять страницу» · push
    ├─ Любимое (library) — tab (root) · открывается: «Сохранить»
    └─ Профиль (profile) — push · открывается: «Профиль»
```
