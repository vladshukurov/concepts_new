# Архитектура

13 экранов, три корневых раздела, как в ВК Музыке: «Главная», «Практики», «Любимое». Профиль открывается push‑переходом из шапки главной. Detail и search — push, player — полноэкранно, result — завершение player. Мини-плеер над таб-баром ведёт в player с любого корня. Back возвращает на непосредственного родителя; root‑табы не складываются в стек.

Свои звуки — файлы и записи на устройстве; обложка практики — кадр с камеры или снимок из «Фото» — хранится вместе с практикой. Сохранённые сессии и история живут в CoreData с опциональной синхронизацией CloudKit private database.

Background audio — capability, а не пользовательское разрешение. Associated Domains не заявлен: диплинков нет. Камера и «Фото» запрашиваются только из раздела «Обложка» в «Новой практике»: камера снимает место, где звучит запись; доступ к «Фото» нужен, чтобы показать наверху снимки дня записи звука (PhotoKit по дате файла), — системный пикер без доступа так не отберёт. Уведомления запрашиваются кнопкой «Напоминать в 22:10» на итоге сессии; после разрешения напоминание видно на итоге и на главной. С локскрина «Открыть «Мантру»» возвращает в плеер.

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | «Снять обложку» в новой практике | Новая практика | Обложку можно выбрать в «Фото» или оставить практику без обложки | Низкий |
| `NSPhotoLibraryUsageDescription` | «Выбрать в «Фото»» в новой практике | Новая практика | Обложку можно снять камерой или оставить практику без обложки | Низкий |
| `UIBackgroundModes: audio` | «Слушать в фоне» в плеере | Тихий берег | Без фонового режима звук останавливается при блокировке, практика продолжается с открытым экраном | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment` | «Напоминать в 22:10» после сессии | Сессия завершена | Напоминания нет, практика остаётся в «Продолжить» и «Истории» | **Условный** — Регистрация APNs через SDK провайдера |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Вход по номеру (phone) — старт, без таб-бара · открывается: старт
    ├─ Пароль (password) — push, без таб-бара · открывается: «Далее»
    │   └─ Аккаунт (account) — push, без таб-бара · открывается: «Профиль и аккаунт»
    │       └─ Удаление аккаунта (deleteaccount) — push, без таб-бара · открывается: «Удалить аккаунт»
    └─ Создать аккаунт (register) — push, без таб-бара · открывается: «Создать аккаунт»
        └─ Пароль нового аккаунта (registerpassword) — push, без таб-бара · открывается: «Далее»

Главная (home) — tab (root, start) · открывается: «Продолжить без аккаунта», «Войти» …
    ├─ Практики (discover) — tab (root) · открывается: «Все практики»
    │   ├─ Поиск (search) — push · открывается: «Поиск», «Поиск по своим практикам»
    │   └─ Новая практика (new) — modal · открывается: «Новая практика», «Снять обложку» … · camera, photos
    │       ├─ Обложка (capture) — fullscreen · открывается: «Снять обложку» (camera)
    │       └─ Обложка из «Фото» (pick) — system picker · открывается: «Выбрать в «Фото»» (photos)
    ├─ Тихий берег (detail) — push · открывается: «Тихий берег», «После дождя» …
    │   └─ Тихий берег (player) — fullscreen · открывается: «Слушать «Тихий берег»», «Синий час» … · audio
    │       ├─ Экран погас (background) — system · открывается: «Слушать в фоне» (audio)
    │       └─ Сессия завершена (result) — modal · открывается: «Завершить» · push
    ├─ Любимое (library) — tab (root) · открывается: «Вся история», «Сохранить в «Любимое»» …
    └─ Профиль (profile) — push · открывается: «Профиль»
```
