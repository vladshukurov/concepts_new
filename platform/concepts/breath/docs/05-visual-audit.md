## Матрица системных интеграций

| Интеграция | Видимый путь | Результат | Отказ |
|---|---|---|---|
| Camera | Наброски → песня → «Снять текст из блокнота» | prompt → видоискатель с рамкой страницы → «Текст добавлен», в песне «Текст · фото из блокнота» | песня, пустое состояние |
| Photos | Наброски → + → «Добавить из «Фото»» | prompt → видео и снимки 14 июля → «Репетиция · видео 1:26» в наброске | новый набросок, пустое состояние |
| Push | Песня → «Снять текст из блокнота» → «Напомнить вернуться завтра» | prompt → «Завтра в 20:00 · Припев про дождь» на главной | «Текст добавлен» без напоминания |
| Background audio | Плеер → «Слушать в фоне» | capability → локскрин, «Открыть «Мотив»» → плеер | звук только с открытым экраном |
