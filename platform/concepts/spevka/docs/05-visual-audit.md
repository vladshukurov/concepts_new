# В унисон — визуальный аудит

Автоматические проверки — `npm run test`, `lint`, `audit`, `audit:grid`, `access` — зелёные. Каноническое evidence визуальной вычитки живёт в `artifacts/quality/<run>/review.json`; критик для черновика не запускался.

## Проход автора

- Длинные строки-следы фоновых режимов перенесены в подпись строки с переносом — заголовки больше не обрезаются.
- Поля новой спевки и нового чата — без серой подложки, с тонкой линией снизу.
- Шкала «кто пришёл» — 32 деления; клетка Оли загорается после отметки по сети зала.
