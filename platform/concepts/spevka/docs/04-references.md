# В унисон — референсы

Режим — полная мимикрия категории «мессенджер» (профиль `kernel/archetypes/messenger.json`). Бренд, логотипы и токены референсов не переносятся: интерфейс собран на ядре `vk-light`.

## Что взято из категории

| Паттерн | Референс | Экран | Наблюдаемое поведение |
|---|---|---|---|
| chat-list | Telegram, WhatsApp | `chats` | Чаты по времени, непрочитанные, поиск |
| folders | Telegram | `chats` | Чипсы «Хор», «Личные», «Непрочитанные» фильтруют список на месте |
| chat | Telegram, WhatsApp | `choir`, `altos`, `regent` | Пузыри, имена в группе, галочки прочтения, закреп под шапкой |
| voice-message | Telegram, WhatsApp | `altos`, `record` | Голосовые с партией, запись с отменой |
| calls | WhatsApp | `calls`, `call` | История с фильтром пропущенных, системный экран звонка |
| attachments | WhatsApp | `attach`, `geo` | Недавние кадры, камера, файл, геопозиция, контакт |
| saved-messages | Telegram | `saved` | Чат с собой: ноты, пересланное от регента, голосовая заметка |
| contacts-sync | Telegram, WhatsApp | `contacts` | Кто из адресной книги уже здесь, кого пригласить |

## Первичные наблюдения

- **Telegram для iOS, групповой чат.** Закреп — полоса под шапкой, касание имени группы открывает сведения. → Спевка дня в закрепе ведёт в «Кто пришёл».
- **WhatsApp для iOS, голосовые и звонки.** Голосовые играют подряд, звонок — из шапки через CallKit. → «Слушать мою партию подряд» продолжает записи с погашенным экраном; звонок регенту из шапки.
- **Apple HIG, Communication notifications.** Отправитель через INSendMessageIntent, превью — Notification Service Extension. → Уведомления с отправителем, расшифрованным текстом и голосовым.

## Чем «В унисон» не похож на референсы

1. Партии собраны из переписки чата голоса и играют подряд.
2. Отметка на спевке по сети зала и расписание, которое правит Календарь.
3. Видео концерта из роликов участников, собранное ночью.

## Соседи по портфелю

«Сбор» — мессенджер поездок группой, от него взята структура экранов. «В унисон» держится на ежедневной партии и спевках дважды в неделю, а не на одной поездке.
