# Встык — App Store и review notes

Photo & Video. Аккаунт опционален: «Продолжить без аккаунта» сразу открывает проекты. Core loop доступен в авиарежиме.

Заявлены девять достижимых возможностей: Camera, Microphone, Photos read, Photos add, Location When In Use, Local Network/Bonjour, Background Audio, Notifications (локальное уведомление о готовом черновике) и ATT (бесплатная версия с рекламой). Associated Domains не заявлен: диплинков нет.

Review route:

1. Главная → «+» → строка «Место» спрашивает геопозицию и подставляет «Каркаралинск · здесь»; отказ открывает поле для ручного ввода.
2. Проект → «Из Фото» спрашивает Photo Library и открывает видео за 14–16 августа; после «Добавить» проект показывает 42 видео. «Из Файлов» работает без доступа.
3. «Собрать черновик» → «Сообщить, когда черновик соберётся» спрашивает уведомления; свитч включается.
4. «Открыть черновик» → «Снять вступление» спрашивает Camera, затем Microphone; вступление встаёт первым в «Начале фильма». Отказ — пустое состояние на месте кнопки.
5. Черновик → «Смотреть» → кнопка показа на ТВ спрашивает Local Network; после выбора телевизора «Гостиная» (Chromecast) плеер показывает «Идёт на телевизоре «Гостиная»». «Картинка в картинке» продолжает видео поверх других приложений (фоновое аудио).
6. «Экспортировать» → «Сохранить в Фото» спрашивает add-only; отказ оставляет «Отправить фильм».
7. Главная → рекламная карточка или Профиль → «Реклама» → «Подбирать по интересам» показывает ATT до выбора «Без подбора»; после разрешения карточка на главной меняется.
