# Референсы

- ВКонтакте, лента: шапка с логотипом, запись со значком, фото, голосовым и вложением — для своего дневника растений.
- ВКонтакте, профиль: аватар, счётчики и свои записи — без подписчиков.
- ВКонтакте, мессенджер: диалоги с инициалами, вложения, голосовые.

Копируется продуктовая грамматика, а не бренд: карточка растения, рост по месяцам и полив принадлежат «Вазону».
