# Архитектура

26 экранов, три корневых раздела: «Звуки», «Коллекции», «Профиль». Звук открывается из сетки мест, коллекции или поиска; плеер — полноэкранно, «Где записано» — из плеера и экрана звука; камера — из звука без фото; форма «Новый звук» — модально по «+». Мини-плеер над таб-баром ведёт в плеер с любого корня.

Звуки — файлы из «Диктофона» и «Файлов» на устройстве; места, коллекции и фото мест — CoreData с синхронизацией CloudKit private database. Таймер сна работает на устройстве и затухает громкость.

Background audio — capability, а не пользовательское разрешение. Камера запрашивается только «Снять место» в «Утре в пекарне»; «Фото» — только «Фото того же дня» в новом звуке; уведомления — «Напомнить записать первый снег» в «Зиме 2026».
