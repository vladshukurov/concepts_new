# Вызов — дизайн-система

Тема `vk-dark` ядра: нейтрали, кегли и радиусы VKUI, акцент `#0077FF`.

## Своё

- `.vz-task` — карточка задания точки: номер, задание 24/30, место.
- `.vz-clip-*` — вертикальный ролик команды на весь экран.
- `.vz-camera-*` — съёмка задания: задание поверх видоискателя.
- `.vz-picker-grid` — выбор снятого раньше из «Фото».
- `.vz-banner`, `.vz-channel` — страница квеста как канал.
- `.vz-score`, `.vz-tv-*` — счёт команд и финал на телевизоре.
- `.vz-map`, `.vz-pin` — точка «здесь» на карте.

Кадры — `.ph`, люди и команды — инициалы.
