# Сбор — референсы

Режим — полная мимикрия категории «мессенджер» (профиль `kernel/archetypes/messenger.json`). Бренд, логотипы и токены референсов не переносятся: интерфейс собран на ядре `vk-light`.

## Что взято из категории

| Паттерн | Референс | Экран «Сбора» | Наблюдаемое поведение |
|---|---|---|---|
| chat-list | Telegram, WhatsApp | `chats` | Чаты по времени, непрочитанные, «Вы:» у своих реплик, поиск |
| folders | Telegram | `chats` | Чипсы «Поездки», «Личные», «Непрочитанные» фильтруют список на месте |
| chat | Telegram, WhatsApp | `trip`, `chat`, `lena` | Пузыри, имена в группе, галочки прочтения, закреп под шапкой |
| voice-message | Telegram, WhatsApp | `trip`, `record` | Волна и длительность, запись с отменой |
| video-note | Telegram | `trip`, `lena`, `album` | Кружки в чате и альбоме |
| calls | WhatsApp | `calls`, `call` | История с фильтром пропущенных, системный экран звонка |
| attachments | WhatsApp | `attach`, `geo` | Недавние кадры, камера, файл, геопозиция, контакт |
| saved-messages | Telegram | `saved` | Чат с собой: билеты, пересланное, голосовая заметка |
| contacts-sync | Telegram, WhatsApp | `contacts` | Кто из адресной книги уже здесь, кого пригласить |

## Первичные наблюдения

- **Telegram для iOS, групповой чат.** Закреплённое сообщение — полоса под шапкой, касание имени группы открывает её сведения. → Сбор поездки живёт в закрепе и ведёт в перекличку; сведения поездки открываются по имени.
- **WhatsApp для iOS, вложения и звонки.** Скрепка открывает выбор вложения, звонок — из шапки через CallKit, история звонков — отдельная вкладка. → Тот же набор вложений, звонок отставшему из шапки личного чата.
- **Apple HIG, Communication notifications.** Сообщения показывают отправителя через INSendMessageIntent, превью добавляет Notification Service Extension. → Экран блокировки с отправителем, чатом и превью кадра.

## Чем «Сбор» не похож на референсы

1. Сбор и перекличка — часть чата поездки, отметка ставится по сети отеля.
2. Программа поездки правит уже добавленные события Календаря.
3. Wi‑Fi места из QR одного участника и фильм дня, собранный ночью.

## Соседи по портфелю

«Караван» (набор ОК) ведёт колонну машин в дороге, «Экспедиция» — поход по маршруту офлайн. «Сбор» — мессенджер: поездка в нём — один из чатов, а продукт держится на переписке и звонках.
