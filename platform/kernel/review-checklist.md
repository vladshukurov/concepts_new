# Журнал правок владельца → проверки

Каждое «оо, а тут…» владельца становится правилом, которое ловит self-review (`npm run selfreview -- <slug>`) или ревьюер (`kernel/review-prompts.md`). Новая правка — новая строка здесь и, если ловится машиной, запись в `review-checklist.json`. Ревьюеры читают этот файл целиком.

| Правка владельца | Правило | Где ловится |
|---|---|---|
| «Wi‑Fi дог-парков звучит нереально тупо» | Доступ — так, как сделало бы реальное приложение категории; без натяжек | `bannedStretches`, скептик доступов |
| «Свет комнаты», «цвет из фото» для визуала | Камера и фото — на своём контенте, не на декоре | `bannedStretches`, скептик доступов |
| Push «раз в месяц новые ритмы» свитчем | Push — у своего события («Напомнить…», «Сообщить, когда…») | `bannedStretches`, `npm run access` |
| Keychain «тап по виджету» | Расшифровка превью уведомлений или общая связка с автозаполнением | `bannedStretches`, `npm run access` |
| «Не смог создать поездку» | Главный объект создаётся формой, «+» ведёт в форму | `required.*.create*` с `targetForm`, новичок |
| «Нет плеера, фона и сворачивания» во «Встыке» | Видео: плеер, свернуть, мини-плеер, PiP или локскрин, ТВ, клипы | `required.vk-video` |
| «Пауза отдаёт снекбар» | Состояние меняется на месте (data-toggle), не тостом | `toastForbidden` |
| Плеер «неаккуратный и туповатый» | Музыка — `musicControls` (назад/вперёд залитые, кнопка 64) | `required.vk-music.fullplayer`, дизайнер |
| «Мессенджеры абсолютно одинаковые» | У каждого своя фича со своей механикой, без общего шаблона вкладки | `npm run sameness`, портфельный взгляд ревьюера |
| «Маятник» в Lifestyle | Категория = категория референса | `categories` |
| Названия «Сбор», «Мантра» | Название по правилу набора, без негативных ассоциаций | `namePrefixes`, ревьюер |
| «Нет ощущения своего контента» | Свой контент читается: «Без названия 14 · напел в метро», а не каталог | новичок, дизайнер |
| Серые кадры в видео | В ВК Видео и Музыке — фото из атласа | дизайнер |
| Голосовое в записи и чек-лист «выглядят нереально плохо» | `entry` с голосовым, `ui.checklist` | дизайнер |
| Строка открывает чужой чат | Каждая строка открывает свой объект | `npm run flows`, новичок |
| Сетка выбора фото, виджет, локскрин «как в iOS» | Только `ui.photoPicker`, `ui.homeScreen`, `ui.lockScreen` | дизайнер |
| «Картинка в картинке» на пустом «Домой» без значков | PiP — только `ui.homeScreen({ app, pip })` | дизайнер |
| «Метроном» с первого взгляда как «Мотив» | Своя механика концепта видна на главной, а не только в глубине | дизайнер, новичок |
| Вкладка «Растения» копирует «Рецепты» шаблона | Вкладка-ценность строится вокруг своей механики, шаблон — только каркас | `npm run sameness`, новичок |
| «Клипы сделаны очень плохо» | Клипы — только `ui.clip` (кадр во весь экран, колонка действий справа, тёмный таб-бар) | дизайнер |
| «Картинка в картинке должна быть маленькой кнопкой в плеере» | PiP — иконка в плеере (`ui.player({ pip })`), не большая кнопка под ним | дизайнер |
| «Профили вообще не проработаны, нет настроек приложения» | Профиль — живой (своя статистика, своё за период, вход в настройки); экран «Настройки» с группами | `required.*.settings`, дизайнер |
| Шапка «Метронома» съехала под статус-бар | Герой-обложка первым блоком уходит под статус-бар (ядро) | дизайнер |
| «В профиле нет выхода из приложения» (Виляй) | В профиле — шестерёнка → «Настройки» → «Аккаунт» → «Выйти» | `required.*.settings`, новичок |
| Йоркшир в ролике «Рыжик» (ретривер) | Кадр показывает того, кто назван в подписи: один герой — одна внешность | дизайнер |
| «Миниплеер в Видео должен быть справа снизу, как картинка в картинке» | Видео сворачивается в `ui.videoMini`, полоса `miniPlayer` — только для музыки | `required.vk-video.mini` |
| «Чтобы концепты ощущались разными: не везде такой плеер, топбар можно без аватарки» | Узнаваемость референса — да, но шапка, главная и плеер у каждого свои; сверка с соседями по контактным листам перед сдачей | дизайнер, `npm run sameness` |
