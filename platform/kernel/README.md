# Ядро и пайплайн концепта

Точка входа в ядро: как сегодня делается концепт, какой командой проверяется каждый шаг и где лежат подробности. Правила интерфейса и запреты — в корневом `CLAUDE.md`, поиск идеи — в `PLAYBOOK.md`.

## Порядок работы

| Шаг | Что делаем | Чем проверяется |
|---|---|---|
| 1. Идея | Ниша, инсайт, атаки критика — фазы 0–4 `PLAYBOOK.md`. Для каждого доступа — сильный паттерн из `access-model.json`, а не переключатель в настройках | `npm run proof -- <slug>` — ворота готовности спеки |
| 2. Спека | `concept.json` — единственный источник правды. Тема выводится из набора: тёмная только у мимикрии Музыки и Видео, ОК — `ok-light`, остальное — `vk-light` | валидатор при каждой сборке |
| 3. Модель домена | `model.mjs`: «сейчас» через `moment()` из `world.mjs`, люди и их фото, данные и сущности с состояниями. Экраны берут имена, время и числа отсюда | таблица `domain-model` в доках; линтер сверяет день недели с датой |
| 4. Экраны | `screens/<id>.mjs` из функций `components.mjs` — каталог в сторибуке (`npm run storybook`). Своё — только доменные блоки в `styles.css` с префиксом концепта | `npm run lint`, `npm run audit`, `npm run audit:grid` |
| 5. Синхронизация | `npm run sync -- <slug>`: рендер экранов, главные действия в спеке, замыкание срезов прототипов | — |
| 6. Доступы | Жест в сценарии, видимый результат — экран, строка данных или свитч; пустое состояние `ui.denied` у ключей, без которых фича не работает | `npm run access -- <slug>` — 100% |
| 7. Сборка и тесты | `build → shots → build → test` | `npm run test -- <slug>` |
| 8. Доки | Генерируемые блоки пересобираются на каждой сборке; ручной текст — только «почему». Устаревшее помечается `<!-- @history -->` | противоречия доков и спеки — в `npm run lint` |
| 9. Критик | `npm run review -- <slug>`; отдельный агент проходит `critic-rubric.md` | blocker и major закрыты до показа |
| 10. Готово | Все пункты переноса | `npm run migrate:check -- <slug>` — все ✓ |

Эталон на новом ядре — `concepts/looks/`: модули экранов, модель домена, мессенджер, 21 из 21 доступа, доки с генерируемыми блоками.

## Файлы ядра

| Файл | Что это | Статус |
|---|---|---|
| `components.mjs` | компоненты-функции оболочки `.ui` | основа экранов |
| `base.css` | оболочка `.ui` и три темы (с ~1000-й строки); выше — старый слой для концептов, ещё не перенесённых | старый слой удаляется после миграции |
| `engine.js` | движок прототипа: переходы, доступы, тосты | действует |
| `icons.svg` | спрайт Lucide, собирается `scripts/gen-icons.mjs` из списка `ICONS` | действует |
| `world.mjs` | канон мира: «сейчас» 9:41, дата с правильным днём недели, форматы времени, расстояний и денег, правила про людей | действует |
| `access-model.json` | модель доступов: что даёт, сильные и слабые паттерны, обязательный результат | действует |
| `storybook-samples.mjs` | примеры компонентов для `dist/storybook.html` | действует |
| `critic-rubric.md` | рубрика критика до показа | действует |
| `ui-contract.md` | контракт экрана в спеке: pattern, navigation, states, hierarchy | действует |
| `positioning-contract.md` | мимикрия и отстройка: что знакомо и что своё | действует |
| `deliverable.md` | формат итогового HTML-файла концепта | действует |
| `ios-chrome.md` | системный хром iOS: статус-бар, алерты, листы | действует |
| `app-store-assets.md` | ассеты App Store | действует |
| `quality-contract-v2.md` | машинная готовность спеки (`npm run proof`) | действует |
| `quality-pipeline-v4.md` | review bundle и доказательства (`npm run review`, `npm run check`) | действует |
